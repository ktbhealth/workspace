ktbhealth workspaceOne root for every ktbhealth repo

The org metarepo — config-only, managed by lasius. Clones live in repos/, each an independent repo.

lasius docs
GitHub

Config-only

lasius.toml is the source of truth — org, private repos, excludes. Everything else is generated.

8 repos, one root

repos/ holds independent clones — no submodules, each keeps its own history, branches, and remotes.

Editor-ready

ktbhealth.code-workspace is generated on demand — open the whole org as one multi-root workspace.

Quickstart ​

bash
cargo install lasius
git clone git@github.com:ktbhealth/workspace.git && cd workspace
lasius init        # clones all org repos + generates the workspace file
lasius open        # open in your editor

Day to day: lasius update pulls everywhere, lasius status shows the matrix, lasius doctor checks drift. See the lasius documentation for the full command reference.
